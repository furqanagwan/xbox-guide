    Download, install and choose optional title updates (RG-GDK-057 part 2) (#157)

    A title's config lists its updates ([[title_update]]: version, media_id,
    base_version, content_id, optional size, date and changelog), compiled into
    PPCImageInfo::title_updates for the guide.

    rex/ui/guide/title_update.h reads and checks a LIVE/CON package (content
    type, title, disc, base version, and its STFS content ID: the SHA-1 of the
    header region, which covers the whole file and is Xbox Unity's hash),
    downloads it from the first source that has it (Xbox Unity by content ID,
    then title_update_sources URL templates), and installs it as downloaded to
    %LOCALAPPDATA%\<title>\title_updates\<version>.

    At startup the title_update setting picks the executable: the original
    hands over to <title>_tu<version>.exe only when that update is installed
    and built, the update build hands back when it's turned off or removed,
    and the original is always the fallback. An update build mounts its
    installed package without --update_data_root.

    Validated: unit tests, a real Xbox Unity download of Quantum of Solace's
    title update 2, and the handover between the real executables.

    XUI runtime and the Xbox guide (RG-GDK-041 parts 2 and 3) (#129)

    * Read the console's own XUI scenes: XUIZ, XUIS, XUR v8 (RG-GDK-041 part 1)

    The Xbox guide (#127) runs the dashboard's own scenes from the owner's
    system update. This is the format layer:

    - Package / ParseStringTable: XUIZ packages and XUIS string tables.
    - ParseXur: XUR v8 element trees, shared and compound properties,
      gradient stops, figure paths, timelines with compound property paths
      and named frames. The declared object count and full DATA consumption
      check the schema.
    - schema.cpp: property order for the classes the guide, skin and
      achievement scenes use (interoperability data only).
      AccountManagementNavButton derives from GuideDashCommandNavButton.
    - SystemUpdate: $SystemUpdate folder or su*_00000000 package through the
      SDK's STFS device, $flash_*.xex resources (plain, basic or LZX), XUIZ
      packages keyed module/resource.

    ADR-011 records the design; docs/xbox-guide.md the format and what is
    inferred. unit_tests [xui] covers every parser with synthetic data;
    [local] decodes every non-Kinect guide scene from REXGLUE_SYSTEM_UPDATE.

    * Run XUI scenes: elements, visuals, timelines, rendering, UI sounds (RG-GDK-041 part 2)

    The runtime the Xbox guide (#127) runs the console's scenes on:

    - Element: builds a scene with skin visuals (named, or named after the
      class, as XUI does), anchoring against the parent's design size,
      named-frame playback (linear, step and eased keyframes, stop and goto
      commands, compound paths such as Fill.FillColor copied per element),
      sound cues fired as the playhead crosses them, Nav* navigation that
      passes over hidden controls, and Focus/KillFocus/InitFocus.
    - ResolveFile: sharedres://, xam://, the scene's package, then the skin
      and shared packages skin visuals keep their media in.
    - Render: figures (solid, linear and radial gradients, Bezier outlines,
      strokes), images, nine-grids and text (style bits, ellipsis, drop
      shadow, rotation through vertex transform) on an ImGui draw list.
    - DecodeXmaFile: single-stream RIFF XMA UI sounds through the xmaframes
      decoder; UiSoundPlayer plays them on a separate XAudio2 engine.

    The XMA frame synthesis and XUIZ/XEX byte builders move to shared test
    headers. unit_tests [xui], [ui_sound]; [local] plays GuideMain's 2To3
    blade shuffle and decodes every guide sound (all audible).

    * The Xbox guide over a running title (RG-GDK-041 part 3)

    Back+Start (or the Guide button, or Home) opens the console's own Metro
    guide, run from the owner's system update on the XUI runtime:

    - XboxGuide hosts GuideMain in the HUD backdrop (hudbkgnd ClosedToHalf),
      brings the tab in with <tab>Close, shuffles blades with iToj, and
      drives focus and presses through the skin visuals' named frames and
      sounds. Controls it cannot honour stay in the menu, disabled.
    - Games & Apps > Achievements: 802_Achievements grid from the
      AchievementManager (XDBF icons, unearned/secret images, focused
      achievement header, count), 828_AchievDetails on A.
    - Xbox Home (Y or the Home tab) and Turn Off Console ask through the
      skin's XuiMessageBox3 in the backdrop's error frame; Yes closes the
      window through its normal path.
    - While open: guest input blocked, XN_SYS_UI, XamIsUIActive (new
      xeXamAdd/RemoveSystemUI).
    - ReXApp: xbox_guide / xbox_guide_system_update cvars, background asset
      load, Segoe UI fonts in the atlas, a pad chord poller, bind_xbox_guide
      (Home added to the key names).
    - Runtime: list population from the item template, disabled focus and
      press frames, RemoveChild; message box bodies wrap.

    unit_tests [guide] covers the chord and pad handling. Checked with
    Quantum of Solace (GDK Release): tabs, achievements, the Xbox Home prompt

    The owner's pad (ROG Raikiri II) opens Xbox PC Game Bar with the Xbox

    * Guide settings pages, switchable patches, display resolution (RG-GDK-041)

    Settings > Preferences opens the console's Options scenes: Notifications
    (show, sound), Volume (Game Volume slider on audio_volume), Vibration and a
    Resolution page (match display, 720p, 1440p, 2160p). Settings > Patches and
    Cheats list the title's switchable code patches and turn them on and off
    while it runs; choices are saved in the title's config.

    Codegen: `switchable = true` patches keep the image original and emit both
    versions of each changed word behind g_rex_patch_active flags, listed in
    PPCImageInfo::switchable_patches with a category. Branches are refused.

    By default the title draws at the display's resolution (resolution_scale
    from the monitor, 3 at 2160p), and the guide's fonts are baked for the
    display so text is sharp at 4K.

    Family Settings, Account Management, Kinect Tuner, Turn Off Console and the
    Media tab are removed from the guide, kept in code so they can return.
    Labels no longer take focus.

    * Build the Xbox guide into every title; register-set patches (RG-GDK-041)

    The guide no longer needs anything from players. Whoever builds a title
    sets REXGLUE_SYSTEM_UPDATE once (CMake or environment) to their own
    console's $SystemUpdate; rexglue_configure_target, which every title
    calls, runs the new `rexglue guide-bundle` to take the four modules the
    guide reads (hud, huduiskin, xam, gamerprofile, about 2.7 MB) and embeds
    them in the executable with .incbin. At run time the guide loads from the
    embedded bundle, offline; the cvar and folder lookups remain as fallbacks
    for builds without one. Nothing from the update ships with the SDK.

    Switchable patches can now also set a register before an instruction,
    optionally only when lr holds a given return address ([[patch.set]]), as
    a trainer's detour does, and may consist of sets alone. Needs lr kept
    (not skip_lr).

    Tests: unit_tests [xui] guide bundle round trip and truncation, [local]
    round trip of the real update, [codegen][patch] register sets. Quantum of
    Solace built with the bundle opens the guide with no system update on
    disk ("using the guide built into the title (2672 KiB)").

    * Manage Game: install a title's DLC from this PC (RG-GDK-041)

    Games & Apps gains Manage Game, on the console's Options scene: the
    title's installed downloadable content (ticked) and content packages
    (STFS, content type 2, this title's ID) found in the DLC folder beside the
    executable or picked with Add Content from This PC (Windows file picker).
    A installs a package with ContentManager::InstallContent off the UI
    thread; the page shows the package's description and install status.

    Checked with 007 Legends (GDK Release): a throwaway type-2 package in DLC
    was listed, installed into the content folder with its header, and shown
    as installed.

      packages keyed module/resource.
